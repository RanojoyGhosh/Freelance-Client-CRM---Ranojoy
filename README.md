# Client Desk — Ranojoy Ghosh

Freelance client CRM: pipeline, clients, follow-ups, payments and team projects.

- The page (`index.html`) holds **no client data and no password**.
- Data lives in a private Google Sheet and loads only after you enter your secret key in **Settings**.
- The Apps Script bridge (`Code.gs`) is kept out of this repository on purpose.

Live page: https://ranojoyghosh.github.io/Freelance-Client-CRM---Ranojoy/
